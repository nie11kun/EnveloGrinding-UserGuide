# 第 4 章：分析工具与精度检验

**`分析工具`** 选项卡用于连接**理论设计仿真**与**车间三坐标/轮廓仪实测检验**，形成闭环质量控制。

## 三大分析子模块

| 子选项卡 | 输入对象 | 核心输出与工程价值 |
| :--- | :--- | :--- |
| **[4.1 工件轴向截面计算](axial_section.md)** | 砂轮齿形 `.dxf` + 工件/磨削参数 | 理论轴向截形 `.dxf`、2D/3D 喉部螺旋曲线 HTML 与 **`计算工件数据`** 速算表 |
| **[4.2 DXF 文件对比](dxf_compare.md)** | `2 ~ 3` 份 `.dxf` 轮廓文件 | 合并叠加 `.dxf` 与直观的多曲线颜色叠加对比 HTML |
| **[4.3 曲线误差对比](curve_deviation.md)** | 基准曲线 + 对比曲线 `.dxf` | 法向误差曲线 `*-differences.dxf`、超差高亮图与 RMS/均值/成功率统计 |
