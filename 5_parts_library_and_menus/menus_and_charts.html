5.2 菜单栏、参数配置与 2D/3D 图表操作

除主窗口顶部的 3 大主选项卡 × 3 子选项卡（共 9 个子功能页） 外，顶部菜单栏提供语言切换、在线升级、零件库调用与官方资源入口；所有绘图与分析模块产出的独立 HTML 图表均内置统一的 Plotly 交互操作规范。

二、本地配置文件与持久化机制

EnveloGrinding 将当前工作区所有输入项拆分为 3 份独立 JSON 文件，存放在 ~/.eg/（Windows 为 %USERPROFILE%\.eg\）：

  • eg_config_main.json：对应 磨削参数（基本参数、高级参数、其他参数）及界面语言设置；
  • eg_config_draw.json：对应 绘图工具（锥面廓形、XY点位文件、包络蜗杆砂轮截形）；

  • eg_config_tool.json：对应 分析工具（工件轴向截面计算、DXF 文件对比、曲线误差对比）。

  • 何时写入保存：

    • 点击主窗口底部右侧 保存设置，软件校验各页输入并将上述三份配置文件同步落盘；
    • 点击底部左侧主按钮执行计算（如 生成代码、生成截形 等）前也会将有效参数保存，避免计算后丢失输入；
    • 在 设置 菜单切换语言时会即时写入 language_code。
  • 何时读取恢复：
    • 下次启动软件进入主界面时自动加载三份配置文件恢复上次界面状态；
    • 在 零件库 中选中零件点击 导入 时，覆盖这三份配置文件并立即刷新全部界面控件。
  • 输出位置定位：每次点击计算生成 .SPF/.dxf/.html 成功后，Windows 下会自动调用资源管理器定位并高亮选中新生成的文件或目录（无需额外翻找）。

三、2D/3D 交互式图表通用操作

运行 锥面廓形、XY点位文件、包络蜗杆砂轮截形、工件轴向截面计算、DXF 文件对比 或 曲线误差对比 后，软件会生成单文件自包含 Plotly HTML 并在浏览器中打开：

  • 框选放大与平移：在 2D 图表中按住鼠标左键框选区域即可局部放大齿根圆弧或超差区段；右上角工具栏可在 Zoom（缩放）与 Pan（平移）间切换。
  • 滚轮缩放与 3D 视角：滑动鼠标滚轮围绕光标位置缩放视图；在 3D 啮合/螺旋曲线图中，按住左键拖拽旋转三维视角，右键拖拽平移模型。
  • 视图快速复位与视角保持：双击画布空白处（或点击右上角 Reset axes / Autoscale）可一键还原初始视野；图表内置 uirevision 视图锁定，在切换图层显隐或窗口尺寸变化时不会意外重置当前观察位置。
  • 图例图层开关：
    • 单击图例中的曲线/构件名称，可单独隐藏或重新显示该图层（例如在 3D 图中单独隐藏蜗杆实体只观察接触线）；
    • 双击某条图例项，可快速隔离仅显示该组数据；再次双击恢复全部图层。
  • 一键导出高清图片：点击右上角工具栏相机图标 Download plot as a png，即可将当前局部放大图或 3D 视角直接存为 PNG 用于质检报告。

四、右下角工艺参数与数据解读指南

绘图与包络模块生成的 2D/3D HTML 右下角（及误差对比统计区）通常附带折叠式浮动面板 📊 工艺参数与数据解读指南：

  • 展开与收起：默认状态下以紧凑条形式折叠显示（按钮为 ▸ 展开），避免遮挡几何曲线；点击后展开并显示 ▾ 收起，展开层以最高层级（z-index: 2000）覆盖在图例上方，确保完整阅读不被遮挡。
  • 核心核对信息：卡片内集中列出了当前计算的理论与加工关键参数、圆柱蜗杆共轭摆角 Σ\SigmaΣ、实际槽底直径 df′d_f'df′​ 与切深偏差、有效渐开线起始直径 dsapd_{\text{sap}}dsap​、根切阶梯检验及装配顶隙评估结论，配合 2D/3D 曲线即可完成现场快速复核。
  • 等比例视觉保证：所有截面与廓形 2D 图表均默认锁定物理 1:1 纵横比例，确保目测齿形压力角、槽宽与直线度时不存在坐标轴拉伸失真。
