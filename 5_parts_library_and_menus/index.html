零件库、菜单功能与交互图表

第 5 章：零件库、菜单功能与交互图表

本章介绍 EnveloGrinding 的工件配置复用体系与可视化分析能力，涵盖通过 工具 →\rightarrow→ 零件库 管理整套三配置文件、顶部菜单栏全局入口，以及计算完成后自动打开的 Plotly 2D/3D 交互式图表操作。

本章导读

节次 主题 核心内容
5.1 零件库管理指南 零件库 三列排序表格、新增 / 修改 / 删除 / 刷新 / 导入 按钮功能、命名规则与三 JSON 存储结构
5.2 菜单栏、参数配置与 2D/3D 图表操作 设置 / 工具 / 关于 菜单全清单、本地持久化机制与 Plotly 交互图表及右下角工艺解读卡片用法

核心能力速览

  • 跨模块整套归档与导入：单个零件目录同时保存 磨削参数、绘图工具 与 分析工具 三份配置；执行 导入 时一次性完整覆盖并刷新全软件 9 个子功能页。
  • 顶部三组全局菜单：支持通过 设置 热切换 中文 / English、检查更新 与 更新日志，通过 工具 打开 零件库，通过 关于 访问 官方网站、用户手册 与 关于我们。
  • 交互式 HTML 图表与工艺卡片：2D/3D 绘图窗体支持框选放大、滚轮缩放、图例单击显隐/双击隔离、相机截图导出与右下角可折叠 📊 工艺参数与数据解读指南 浮动面板。
