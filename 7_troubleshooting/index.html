常见提示与故障排除

第 7 章：常见提示与故障排除

本章汇总 EnveloGrinding 在授权验证、磨削参数输入、包络仿真与分析比对中最常遇到的系统提示与故障处理步骤。

一、授权与登录问题

现象或提示原文 常见原因 排查与解决方法
未检测到合法的加密狗、登录会话或本地离线授权，禁止执行计算！ 本机未接入有效加密狗，也未完成在线账号登录或离线 .lic 授权激活 重启后在登录框选择对应模式验证，或在 硬件ID 页签点击 导入授权文件 导入有效 eg_license.lic
加密狗已断开或会话已失效，无法执行核心计算！ 软件运行过程中拔出了 Sentinel 加密狗或 USB 接触不良（每 3 秒检测一次） 将加密狗直连主机主板 USB 接口避免扩展坞供电不足；断狗保护关闭后重新插稳再启动软件
该账号已被绑定至其他设备，无法在当前设备登录！ 账号登录严格绑定注册时的硬件特征码，更换工控机/电脑后触发绑定拦截 使用绑定当前设备的账号登录，或点击 获取设备ID 后联系管理员重新绑定 / 签发离线 .lic
数字签名校验失败 (授权已被非法篡改) / 授权设备不匹配 所选 eg_license.lic 文件损坏、被手工修改或并非对应本机硬件 ID 签发 核对 硬件ID 页签中 获取设备ID 读取的完整 ID，重新向技术支持申请匹配本机的 .lic 文件

二、磨削参数校验与 NC 程序问题

现象或提示 常见原因 排查与解决方法
最大直径必须大于等于最小直径 或 请输入有效的数字 最大砂轮直径 小于 最小砂轮直径，或存在空白/非法数字字段 检查 基本参数 与 高级参数 所有数值项，确保 最大砂轮直径 >= 最小砂轮直径 且 砂轮直径间隔 > 0
生成程序后找不到 .SPF 目录位置 输出程序路径 指向层级较深，或未留意软件自动新建了 PC_<中心距> 子目录 成功弹窗后资源管理器会自动定位高亮目标目录；也可根据 中心距 核对路径下的 PC_xxx_xxxx 文件夹
勾选 Siemens程序加密 后目录里只剩 .cpf 启用加密后，软件调用西门子加密工具生成 .cpf 并按安全逻辑移除明文 .SPF 如需明文核对参数头或坐标系，先取消勾选 Siemens程序加密 重新 生成代码；上机加工保留 .cpf 即可
Siemens程序加密 复选框呈灰色无法勾选 该功能依赖 Windows 平台下西门子专用加密组件，在 macOS 版本中默认禁用 在 Windows 环境下生成加密程序，或在 macOS 先导出 .SPF 后再传至目标 Windows 电脑加密
单件磨削总深度或余量与机床实切不符 未留意 磨削总深度 不是 磨削步进 整数倍时的自动向上取整，或绿色微调框尚存非零补偿值 核对 磨削总深度 右侧绿色微调框与 高级参数 各绿色补偿框，确认是否保留了历史试磨微调值

三、包络截形与绘图工具问题

现象或提示 常见原因 排查与解决方法
包络蜗杆砂轮截形 提示 Sn 无法求解或变位超出合理范围 给定的 中心距、模数与目标 蜗杆法向齿厚中值 Sn 物理矛盾，导致齿顶变尖或齿槽过窄 核对 法向模数 Mn、法向压力角 αn (°) 与 蜗杆分度圆直径 d1 是否与图纸一致，或清空 Sn 改用已知 刀具变位系数 x
2D / 3D 结果提示齿根台阶或可能存在根切 负变位过大或负向 中心距补偿量 Δa (mm) 过深，导致齿侧侵入有效基圆以下 检查计算卡片中 有效渐开线起始直径 dsap 与基圆 db 关系，并打开 _11_Tooth_Root_Detail_Comparison.dxf 核对根部交线，必要时减小负补偿幅值
XY点位文件 打开后报错或预览图空白 选入的文本文件不是有效数值坐标列，或 XY 数据索引号（如 01 / 02）与实际列顺序不匹配 用记事本确认输入 .txt / .dat 的列分隔结构及索引号（索引从 0 开始），必要时调整 交换 XY 数据 或双击画布空白处复位视野
对 修整延长齿高 设为 0.0 与 > 0 的选型疑惑 未区分“砂轮自带防干涉倒角”与“纯直线截形 + CNC 额外修缘”两条工艺路线 设 0.0 可保留 7 齿包络防干涉倒角、机床走标准联动即防干涉；设 > 0（如 5.0） 砂轮易修成纯直线，但两端需在 CNC 中额外编入 Z/C 轴修缘动作

四、分析工具与误差统计问题

现象或提示 常见原因 排查与解决方法
工件轴向截面计算 结果或 计算工件数据 明显偏离图纸 中心距、蜗杆喉部直径、蜗轮齿数 或 砂轮分度圆齿顶高 与所选砂轮 .dxf 不配套 确认 砂轮分度圆齿顶高 严格等于 锥面廓形 中的 中径齿顶高；选 平面 模式时同时检查 偏移角、偏移距离 与 中心偏移角度
曲线误差对比 中 成功率 极低（例如低于 10%）或出现大量红色点 所设 最大误差距离 小于实际工件整体偏移量（例如实测偏移 0.27 mm 时仅设 0.1 mm），或两条 DXF 基准零点未对齐 先在 DXF 文件对比 中叠加观察两曲线相对位置；若存在整体余量差，将 最大误差距离 适当放宽（如 0.5 ~ 0.8 mm）观察真实分布后再调零
DXF 文件对比 提示缺少第 3 个文件或少于 3 条曲线可比 界面共提供 DXF 文件 1、DXF 文件 2、DXF 文件 3 三个输入框 若只有两份 .dxf 需要叠加对比，只需将其中任意一份路径同时填入第三框即可
浏览器打开 .html 图表显示卡顿或空白 本地浏览器脚本限制、旧标签页缓存，或一次性载入超高密度采样点 使用现代 Chromium 内核浏览器（Edge / Chrome）直接打开本地 .html；在图例中暂时隐藏非关注图层也可显著提升交互流畅度

五、日志定位与支持准备清单

当遇到未捕获异常弹窗或技术支持需要进一步定位问题时，可按以下清单收集排查材料：

  1. 异常日志文件 error.log：前往本地配置目录 ~/.eg/error.log（Windows 资源管理器地址栏直接输入 %USERPROFILE%\.eg\ 即可打开，内含完整异常时间戳、线程与堆栈追踪）。
  2. 当前版本号：从软件主窗口标题栏读取当前版本号（如 v1.19.0），或通过顶部菜单 设置 →\rightarrow→ 更新日志 查看版本详情。
  3. 异常现场截图：保留出现异常的功能页签完整截图（包含所有输入参数及弹窗提示原文）。
  4. 脱敏配置文件与示例输入：打包 ~/.eg/eg_config_*.json（或从 零件库 导出的指定零件子目录）及复现所用的 DXF / .dat 样本，并注意提前移除内部敏感客户名或路径信息。
