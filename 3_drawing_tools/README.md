# 第 3 章：绘图工具与砂轮截形设计

**`绘图工具`** 选项卡包含三个专业子模块，分别满足**规则锥面梯形砂轮绘制**、**测量/外部 XY 点云转换**以及**高精度包络蜗杆砂轮截形仿真设计**需求。

## 三大子模块选型对照

| 子选项卡 | 适用场景 | 核心输入 | 关键输出 |
| :--- | :--- | :--- | :--- |
| **[3.1 锥面廓形](conical_profile.md)** | 已知砂轮中径宽、齿顶高、齿底高与左右半角的规则梯形砂轮 | 5 项几何尺寸 + 左右半角补偿 | 1:1 梯形 `.dxf`（含 `2 mm` 齿根延伸）+ 2D 交互 `.html` |
| **[3.2 XY点位文件](xy_points.md)** | 将三坐标/轮廓仪 `.txt` / `.dat` 点位文件转为 CAD 曲线 | 点位文件或文件夹、索引号、比例/镜像 | 离散曲线 `.dxf` + 2D 交互 `.html` |
| **[3.3 包络蜗杆砂轮截形](enveloping_profile.md)** | 由蜗杆与蜗轮图纸反求高精度二次包络砂轮修整截形并评估质检 | 5 大分组 22 项参数（含主动修形 $\Delta\alpha / \Delta a$） | 主截形 `.dxf` + 2D/3D `.html` + **11 份全工序质检 `.dxf`** |
