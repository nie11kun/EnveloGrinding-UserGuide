# 第 2 章：磨削参数与 NC 代码生成

**`磨削参数`** 选项卡用于配置包络蜗杆工件几何、砂轮直径范围、机床五轴机械尺寸与对刀基准，并一键批量生成西门子数控系统（`.SPF` / `.cpf`）多轴联动磨削程序。

## 本章导读

| 节次 | 对应子选项卡 | 核心内容 |
| :---: | :--- | :--- |
| **2.1** | **[基本参数详解](basic_params.md)** | 全 18 项工件、工艺与加密参数（含 **`平面`** / **`锥面`** 条件显隐与导程角自动回填） |
| **2.2** | **[高级参数（机床基准与对刀）](advanced_params.md)** | 全 9 项 `A / B` 轴机械尺寸与 `X / Z / B / C` 对刀基准及绿色实测补偿框 |
| **2.3** | **[其他参数与 NC 程序输出解读](other_and_nc_output.md)** | **`程序头信息`**、`PC_xxx` 输出目录、`.SPF` 代码结构与外部全局变量速查 |

## 工艺参数与输出流转

1. **`基本参数`** 决定工件包络方式（`平面` / `锥面`）、摆动加工范围、磨削余量分层及砂轮直径覆盖区间；
2. **`高级参数`** 将理论分度圆运动映射到具体机床的 `A` 轴、`B` 轴机械偏置与工件中点对刀坐标；
3. **`其他参数`** 写入图号、模数、压力角等注释头，方便现场操作员核对程序；
4. 点击 **`生成代码`** 后，软件为区间内每个砂轮直径生成独立子程序，确保砂轮修整变小后仍可无缝切换对应程序保持几何精度。
